# Página: Error 404

## Objetivo

Recuperar navegación cuando una URL no existe y evitar una salida innecesaria.

## SEO

- **URL:** respuesta global para rutas inexistentes.
- **Title:** Página no encontrada | Fleximy
- **Robots:** `noindex,follow`
- **H1:** Esta página no está disponible
- **Estado HTTP:** `404` real, no `200`.

## Contenido

# Esta página no está disponible

Puede que el enlace haya cambiado o que la dirección esté incompleta. Volvé al inicio o elegí una de nuestras soluciones.

CTA primario: Volver al inicio  
CTA secundario: Ver soluciones

## Accesos recomendados

- Probar demos.
- Ver precios.
- Preguntas frecuentes.
- Contactar a Fleximy.

## Buscador opcional

Incorporarlo solamente si el sitio cuenta con suficientes recursos o artículos. Para una web pequeña, los accesos directos son más útiles.

## Medición

Registrar:

- URL solicitada.
- Página de origen.
- Cantidad de errores.
- CTA utilizado para continuar.

## Dirección visual y animación

Usar una escena propia de Fleximy: un pequeño flujo CSS entre “Sitio” y “Panel” aparece interrumpido en el nodo 404. Al mover el cursor o tocar el nodo, la conexión se recompone y conduce visualmente a los accesos principales.

- Mensaje y CTA visibles desde el primer frame.
- Animación opcional y breve.
- Sin juegos que bloqueen la salida.
- Sin ilustración espacial, robot triste o gráfico de error genérico.
- En mobile, mostrar una versión estática o una interacción táctil simple.
