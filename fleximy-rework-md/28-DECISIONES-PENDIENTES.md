# Decisiones pendientes antes de producción

## Marca

- [ ] Confirmar logo definitivo y versiones.
- [ ] Confirmar si existe manual de marca.
- [ ] Elegir tipografía con licencia válida.
- [ ] Confirmar paleta final luego de validar Inicio.
- [ ] Definir si el modo claro/oscuro es necesario. Recomendación: no mantenerlo si no agrega valor.
- [ ] Confirmar que el sitio será solamente en español en la primera etapa.

## Contacto

- [ ] Número real de WhatsApp.
- [ ] Mensaje precargado.
- [ ] Horario comercial.
- [ ] Email comercial.
- [ ] Responsable de responder.
- [ ] Herramienta para agendar reuniones.
- [ ] Tiempo prometido de respuesta.

## Empresa

- [ ] Razón social.
- [ ] CUIT.
- [ ] Domicilio.
- [ ] Email legal.
- [ ] Email de privacidad.
- [ ] Jurisdicción aplicable.

## Producto

- [ ] Qué módulos existen realmente.
- [ ] Qué funciones están operativas.
- [ ] Qué funciones son solamente demo.
- [ ] Cantidad de usuarios por plan.
- [ ] Límites de registros, productos o archivos.
- [ ] Integraciones incluidas.
- [ ] Integraciones adicionales.
- [ ] Política de exportación de datos.
- [ ] Procedimiento al cancelar.

## Precio

- [ ] Modelo de uno o tres planes.
- [ ] Precio real.
- [ ] IVA incluido o adicional.
- [ ] Implementación incluida o separada.
- [ ] Permanencia mínima.
- [ ] Política de actualización.
- [ ] Costos de terceros.
- [ ] Vigencia de propuestas.

## Implementación

- [ ] Plazo base real.
- [ ] Qué inicia el cómputo del plazo.
- [ ] Cantidad de revisiones.
- [ ] Contenido a cargo del cliente.
- [ ] Carga inicial incluida.
- [ ] Capacitación incluida.
- [ ] Criterios de aceptación.

## Soporte

- [ ] Canal.
- [ ] Horarios.
- [ ] Prioridades.
- [ ] Tiempo de primera respuesta.
- [ ] Qué se considera incidente.
- [ ] Qué se considera nueva funcionalidad.
- [ ] Política de mantenimiento.

## Seguridad

- [ ] Rotar valores del `.env` expuesto.
- [ ] Confirmar frecuencia de backups.
- [ ] Confirmar retención.
- [ ] Confirmar procedimiento de restauración.
- [ ] Confirmar aislamiento de datos.
- [ ] Confirmar 2FA.
- [ ] Confirmar logs.
- [ ] Definir objetivo de disponibilidad.
- [ ] No usar SLA hasta contar con compromiso contractual.

## Evidencia comercial

- [ ] Clientes autorizados.
- [ ] Logotipos autorizados.
- [ ] Testimonios reales.
- [ ] Resultados medidos.
- [ ] Capturas reales.
- [ ] Fotografías del equipo.
- [ ] Biografías.

Hasta resolver estos puntos, utilizar casos de uso identificados como ilustrativos.

## Analítica y privacidad

- [ ] Herramienta de analítica.
- [ ] CRM o destino de leads.
- [ ] Consentimiento de cookies.
- [ ] Política de privacidad validada.
- [ ] Términos validados.
- [ ] Tratamiento de datos de clientes finales.
- [ ] Requisitos especiales para educación y menores.

## Recomendación de prioridades

### Antes de validar diseño

- Marca.
- Idioma.
- Soluciones prioritarias.

### Antes de implementar formularios

- Contacto.
- CRM.
- Privacidad.

### Antes de publicar precios

- Modelo comercial completo.

### Antes de producción

- Seguridad.
- Legales.
- Variables.
- Soporte.
- Evidencia real.
